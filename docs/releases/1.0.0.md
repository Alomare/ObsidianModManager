The first release of Obsidian, a mod manager and mod loader for HELLDIVERS (2015).

### Highlights

#### One place for your mods
Added a library with profiles, folders, options and keys for each mod. Your game files are never edited: Deploy writes patches next to them, and Purge takes every one away. Saves are backed up before every deploy.

#### Mods that work together
Added merging for mods that change different parts of the same file, so they run side by side. Conflicts are shown, and the load order decides who wins. Mods people already share run as they are, from a folder or a .zip.

#### Multiplayer guardrails
Added lobby rules for session mods: they switch off where other players haven't agreed to them, and modded missions stay out of the Galactic War. Missions played with the Obsidian Trainer add nothing to your progress, and the loading screen says so.

#### The Obsidian Kit
Added three mods that come with the app: Obsidian Quality of Life for skips and widescreen fixes, Obsidian Trainer for an in-game menu that changes almost anything, and Obsidian API as a library for other mods.

#### Updates and a Wiki
Added in-app updates for Obsidian and for mods that name a GitHub repository, plus a full Wiki in English, Portuguese and Chinese, with guides for making mods.
