### Highlights

#### Mod List

Reworked the mod list with bigger images and smaller switches. Moved versions back to a column before **Scope**, cut **Scope** down to the diamond, and moved descriptions out of the list to a tooltip on the mod.

#### Update Checks

Added a column of update checks between **On** and **Mod**, with a button for each mod, each folder and the whole list. It replaces the single button at the top of the page. Mods that don't name a GitHub repository have no button.
