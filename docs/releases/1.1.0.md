### Highlights

#### Updates Tab

Added an **Updates** tab to Settings with your version, the check and install buttons, and a changelog of every version. New versions and the installed one start open, and older ones start folded. The versions that shipped with the app can be read without a connection. **When a new version is out** stays in **System**, and the new tab links to it.

When a new version is out, the Settings button turns gold and opens on **Updates**.

#### Library Scope

Mods can now declare `"scope": "library"`. A library runs as a session mod while an enabled session mod requires it, and as a client mod the rest of the time. A client mod can build on a library and keep you in the normal matchmaking pool, with Galactic War results still uploading.

Obsidian API is now a library. When it runs as a client mod, it still reads the game's data and answers `false, "needs_session"` to anything that changes the shared game.

### Additions

- Added a window that shows the download and install of a new Obsidian version, on any page.
- Added a half green, half orange diamond for libraries in the mod list.
- Added `obsidian.scope` and `obsidian.session.guard` to the Loader API, so a library can sort the functions it gives to other mods.
- Added `kit:art` and `obsidian.ui.art` to the Loader API, so a mod can draw art it ships, and a `centered` choice for `obsidian.ui.frame` that keeps a layout in the middle of the window at any UI scale.
- Added `api.ui.open`, `api.ui.close` and `api.ui.menus` to Obsidian API, to open the ship's menus by name.
- Added Updating Obsidian and Writing a library to the Wiki.

### Changes

- Updated Obsidian API to 1.4.0 and Obsidian Quality of Life to 1.1.2.
