A profile remembers which mods are on, the load order, the folders, every option value and key, and the multiplayer switch. Switching profiles changes all of that at once. The library of mods is shared, so a mod only takes space once.

Open the profiles with the **Profile** button at the top of the [Mods](app:mods) tab. From there you can make a new profile, copy one, rename one, delete one, or give one a picture.

> [!TIP]
> One profile for playing with friends and one for solo play is a common setup. The friends profile can leave out every session mod, so you stay in normal matchmaking.

## Sharing a profile

**Export** saves the active profile as a `.zip`. The file holds the profile settings and a copy of every enabled mod, except the mods that come with Obsidian.

**Import** reads such a file. Each mod in it is installed if you don't have it, or if the copy in the file is newer than yours. The profile is added under a name that doesn't clash with yours.

A shared profile is the easiest way to give friends the same set of session mods, so your mods run when you play together ([Playing online](wiki:multiplayer)).
