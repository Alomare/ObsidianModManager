---
title: Obsidian 修改器
group: 入门
summary: 几乎能改变一切的游戏内菜单。
---

Obsidian Trainer 是一个游戏内菜单，可以修改角色、武器、战略配备、敌人、任务以及游戏本身的数值。它随 Obsidian 提供，默认关闭。

## 启用 {#turning-it-on}

在模组列表中启用 **Obsidian Trainer** 并部署。它所依赖的 Obsidian API 会一同启用。在游戏中按 **F6** 打开菜单。可以在模组的“按键”标签页中更改按键。

| 按键 | 作用 |
|---|---|
| 方向键或 W A S D | 移动、更改数值 |
| Enter 或 E | 选择或输入数字 |
| Shift 加左右方向键 | 每次更改十步 |
| Tab | 筛选列表 |
| Esc 或 Q | 返回、关闭 |

菜单也可以用鼠标操作，使用系统的普通光标。

| 鼠标 | 作用 |
|---|---|
| 指向一行 | 选中 |
| 点击一行 | 使用 |
| 点击 `<` 或 `>` | 更改数值，按住可连续更改 |
| 点击数字 | 输入数值 |
| 滚轮或侧边滚动条 | 滚动列表 |
| 右键 | 返回 |
| 标题栏 | 拖动以移动窗口 |
| 右下角 | 拖动以调整窗口大小 |

窗口会记住位置和大小。

菜单打开时角色不会行动。游戏切换画面时（例如任务开始时）菜单会自动关闭。手柄可以在菜单中导航，但只能用 F6 打开菜单。

## 菜单内容 {#whats-in-it}

- **玩家：** 无敌、无限冲刺、速度、传送、重生，以及你拥有的头盔、护甲和披风。
- **武器：** 无限弹药、瞬间换弹、补给，以及你拥有的任何武器或技能。
- **战略配备：** 无冷却、无限次数、瞬间呼叫，以及在光标处投放任意战略配备。
- **敌人：** 停止刷怪、冻结或致盲敌人、消灭敌人、生成更多敌人。
- **任务：** 完成目标、快速撤离、跳过等待、研究样本，以及从飞船开始任意类型的练习任务。
- **世界：** 游戏速度、镜头、HUD、雾、时间和重力。
- **编辑器：** 每种武器、战略配备、敌人和状态效果的数值。
- **进度：** 样本和解锁。
- **控制台：** 开发者自己的命令。
- **更改：** 查看已启用的内容，并可撤销。

只有主机才能执行的操作在选择时会有提示。

## 它不会做的事 {#what-it-wont-do}

- **不会更改经验值或军衔。** 你的总经验值会随下一次普通任务结果一起上传，即使清除后也是如此，因此修改过的数值会进入共享排行榜。
- **不会解锁付费 DLC。** 列表只显示你拥有的物品，其余内容保持游戏的销售方式。
- **不会影响共享战争。** 向银河战争报告的命令会被拒绝，结果仍然被拦截（[银河战争](wiki:galactic-war)）。

> [!WARNING]
> 游戏有防篡改检查，触发后会断开网络直到重启游戏。Obsidian Trainer 只用游戏自身的方式修改受保护的数值，因此不应触发该检查。其他工具和手写脚本可能会触发。

## 与他人一起游戏 {#playing-with-others}

修改器是会话模组，因此大厅中的每个人都需要运行相同的模组或允许会话模组（[联机游戏](wiki:multiplayer)）。如果有未允许的玩家加入，所有更改都会撤销，菜单也会停用，直到该玩家离开。之后你的更改会恢复。

编辑器中的数值在每位玩家自己的游戏中模拟，因此大家使用相同数值时效果最好。

> [!NOTE]
> 启用 Obsidian API 时不会解锁 Steam 成就，因此使用修改器不会获得成就。

## 保留更改 {#keeping-changes}

更改会持续到关闭游戏。在**更改**中，**保留这些修改**会保存你对武器和敌人的修改，只要模组的**保留已保存的修改**选项开启，每次启动时都会恢复。

解锁和样本会写入你真实的存档。Obsidian 会在每次部署前备份存档，包括 Steam 云存档。
